Scribble
Show your agent what you mean.
Scribble is an agent skill that opens a local browser canvas for visual feedback. Drop in screenshots, mark what needs changing, add comments, and send everything back to your coding agent.
The flow
1. Run /scribble while working with your agent.
2. Upload, paste, or drag in one or more screenshots.
3. Draw arrows, circle areas, or drop numbered pins. Attach comments to individual marks.
4. Add an overall message describing your goal.
5. Hit Send to agent. The agent reads your screenshots and feedback, then gets to work.
The feel
A playful sketchbook for giving clear direction.
- A warm canvas, bright ink colors, and rounded controls.
- Hand-drawn accents around a clean, readable interface.
- Satisfying interactions: pins pop into place, tools respond, and submission feels complete.
- Screenshot thumbnails make moving between images easy.
- Undo, zoom, pan, and automatic draft saving keep experimentation comfortable.
The screenshots stay central. Personality comes through the tools and interactions.

How it connects
The skill starts a local server and waits for submission. Scribble returns images, annotation positions, comments, and the overall message in a structured bundle the agent can read.
If the agent session is interrupted, saved feedback remains available to resume. Feedback collection requires no account, hosted backend, or separate model API key.
Success looks like
You can explain a visual change faster with Scribble than by typing where everything is.
